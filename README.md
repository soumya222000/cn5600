# cn5600# CN5006 – Week 1 Portfolio

## Introduction

This portfolio presents the practical activities completed during Week 1 of the CN5006 module. The lab focused on writing and executing basic JavaScript programs using Visual Studio Code and Node.js.

## Learning Objectives

The main objectives of this laboratory session were:

- To understand how to use Visual Studio Code.
- To check and use Node.js.
- To create and execute JavaScript files.
- To understand variables and mathematical operators.
- To use conditional statements.
- To develop a basic arithmetic calculator.

## Task 1: First JavaScript Program

I created my first JavaScript program using the `console.log()` statement to display messages in the terminal.

**File:** `index.js`

## Task 2: Addition of Two Numbers

I used variables to store two numbers and the addition operator (+) to calculate their sum.

**File:** `index.js`

## Task 3: Positive, Negative or Zero

I developed a program that accepts a number from the user and checks whether it is positive, negative or zero using if, else if and else conditional statements.

**File:** `index.js`

## Task 4: Basic Arithmetic Calculator

I developed a calculator that accepts two or more numbers and performs four arithmetic operations:

1. Addition
2. Subtraction
3. Multiplication
4. Division

The program uses user input, variables, arrays, mathematical operators and a switch statement to perform the selected operation. It also checks for invalid inputs and division by zero.

**File:** `calculator.js`

## Testing and Results

The calculator was tested using different numbers to verify that all four arithmetic operations produced the expected results.

Screenshots of the program executions are included in the `screenshots` folder.
